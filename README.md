# Локальный OCR — распознавание русского текста в браузере

Сайт работает **как у shir-man.com/free-ocr**: страница открывается мгновенно, ничего
сама не скачивает. Пользователь нажимает кнопку **«Скачать OCR-движок · ≈13 МБ»** —
движок загружается с прогрессом и остаётся в кеше браузера. Дальше — перетаскиваете
картинки (PNG/JPG/WEBP) или PDF, текст появляется на странице, кнопка «Скопировать».

Отличие от shir-man.com/free-ocr: движок **PP-OCRv5 (кириллица), всего 13 МБ**
(у него GLM-OCR — 658 МБ), и он лежит **рядом со страницей** (папка `models`) —
внешние CDN не нужны вообще, работает в любой сети.

Файлы не покидают компьютер: всё распознавание идёт в браузере (WebGPU, а при его
отсутствии — WASM; переключение автоматически).

---

## Самый простой путь: готовый сайт (папка `site-ready/`)

Внутри `site-ready/` лежит **уже собранный сайт**. Его не нужно собирать:

1. Залейте **содержимое** папки `site-ready/` на любой хостинг (или в подпапку —
   сайт использует относительные пути и работает из `ваш-сайт.ру/ocr/`).
2. Откройте страницу, нажмите «Скачать OCR-движок», пользуйтесь.

Специальные заголовки сервера (COOP/COEP) **не требуются** — однопоточный WASM
включается автоматически. Если хостинг их всё же отдаёт, движок сам начнёт
использовать многопоточность (будет быстрее). WebGPU включается сам, если
браузер его поддерживает.

Поддержка хостингов:

| Хостинг | Что сделать |
|---|---|
| Общий хостинг / cPanel | просто загрузить папку |
| GitHub Pages | залить содержимое `site-ready/` в репозиторий (в корень или `/docs`) |
| Netlify / Vercel | перетащить папку `site-ready/` в дашборд деплоя |
| Cloudflare Pages | то же; при желании добавить `_headers` из таблицы ниже |

Необязательные заголовки (ускоряют WASM многопоточностью, без них всё работает):

```
Cross-Origin-Opener-Policy: same-origin
Cross-Origin-Embedder-Policy: require-corp
```

## Если хотите собирать самому (для разработки)

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # предпросмотр сборки: http://localhost:4173
```

## Структура

```
paddle-ocr-site/
├── site-ready/        ← ГОТОВЫЙ сайт: содержимое этой папки заливать на хостинг
│   ├── index.html
│   ├── assets/        ← JS, CSS, WASM-бинарники onnxruntime (29,5 МБ)
│   └── models/        ← сам OCR-движок (13 МБ): детекция, распознавание, словарь
├── index.html         ← исходник страницы
├── src/
│   ├── main.js        ← интерфейс: drag&drop, очередь, PDF, вывод, копирование
│   ├── ocr.js         ← обёртка над ppu-paddle-ocr (единственный файл с API)
│   └── postprocess.js ← починка кириллических гомоглифов (T→Т, M→М…)
├── public/models/     ← модели для пересборки (копируются в dist/models)
├── package.json
└── vite.config.js     ← относительный base './', заголовки для dev/preview
```

## Ключевые поведенческие детали

- **Движок не качается сам** — только по кнопке или при выборе первого файла
  (файлы, выбранные до готовности, встают в очередь и обрабатываются автоматически).
- Проба WebGPU ограничена таймаутом 5 с, создание сессий — 120 с: при проблемном
  GPU/драйвере вы увидите понятную ошибку и кнопку «Повторить», а не вечную
  «Инициализацию…».
- Страница, открытая как `file://`, покажет подсказку: ES-модули так не работают —
  нужен любой хостинг или `npm run dev/preview`.
- Внешние источники (huggingface.co, hf-mirror.com) используются только если папку
  `models/` удалили из сборки; скачанное кешируется в браузере.
- PDF обрабатывается постранично (pdf.js), страницы разделяются «— Страница N —».

## Требования

Современный Chrome, Edge, Firefox или Safari (актуальные версии). Интернет нужен
только один раз — чтобы браузер получил `models/` с хостинга.
